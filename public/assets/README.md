# JARVIS visual assets

- `jarvis-green.png` is the canonical token image.
- `jarvis-logo-dark.png` is the dark-theme variant.
- `jarvis-logo-light.png` is the light-theme variant.

All images are 1500×1500 RGBA PNG files. Their immutable SHA-256 digests are
recorded in `metadata/metadata.json`. Publish them to durable HTTPS URLs before
mainnet metadata initialization; local relative paths are packaging references,
not production URLs.
